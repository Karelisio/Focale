# Profil de référence (« baseline profile ») écrit à la main : Android compile à
# l'installation le code du démarrage et des parcours fréquents, au lieu d'attendre que l'usage
# le révèle. Les bibliothèques (Compose, Room, Coil, Media3…) fournissent leurs propres profils,
# fusionnés par le plugin Android. Génération et mesure sur émulateur : docs/PERFORMANCE.md.
#
# Syntaxe : H (chaud), S (démarrage), P (après démarrage), L (classe) ; ** couvre les
# sous-paquets. Les noms d'origine sont réécrits par R8 dans la build release.
#
# Choix des drapeaux :
# - S : exécuté avant la première image de la timeline. Ces méthodes sont regroupées dans la
#   partie « démarrage » du DEX : à réserver à ce qui tourne vraiment au lancement.
# - H : appelé souvent ou dans des boucles (défilement, calcul par pixel ou par empreinte) :
#   compilé dès l'installation au lieu d'être interprété puis compilé à la volée.
# - P : utilisé après le démarrage ; avec H, compilé sans alourdir la partie démarrage.
